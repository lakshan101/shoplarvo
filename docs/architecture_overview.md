# System Architecture Overview (`docs/`)

## Tech Stack
- **Frontend**: React 18, React Router v6, Tailwind CSS, Lucide Icons, Vite
- **Backend**: Node.js, Express.js, Mongoose, JWT Authentication, bcryptjs
- **Database**: Live MongoDB Atlas Cluster (`cluster1.eadwrav.mongodb.net/stylehub_db`)

## Port Allocation
- **Client Dev Server**: `http://localhost:3000/`
- **Backend API Server**: `http://localhost:5000/`
